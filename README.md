# Rashu Quiz

Rashu Quiz is a starter Expo (React Native) app for school students to take quizzes, track streaks, and challenge friends.

## Features in this starter

- Login and signup screen for students.
- Student profile setup with grade selection and daily challenge toggle.
- Multi-question quiz flow with local scoring.
- Results screen with next-step prompts.
- Friend challenge list for quick competitive play.
- Auto quizzes that refresh daily.

## Getting started

```bash
cd app
npm install
npm run start
```
